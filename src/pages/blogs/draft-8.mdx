## 1. Typography — Markdown Native

# Heading 1

### Heading 3

#### Heading 4

##### Heading 5

###### Heading 6

Regular paragraph text. Lorem ipsum dolor sit amet, consectetur adipiscing elit. Donec a diam lectus. Sed sit amet ipsum mauris.

**Bold text** is wrapped in double asterisks.
_Italic text_ uses single asterisks.
**_Bold and italic_** uses triple asterisks.
~~Strikethrough~~ uses double tildes.
`Inline code` uses backticks.

## 8. Smart HTML — Inline Semantics

Inside markdown you can drop raw HTML tags anywhere.

<mark>Highlighted text</mark> with the `<mark>` element.

H<sub>2</sub>O — subscript with `<sub>`.

E = mc<sup>2</sup> — superscript with `<sup>`.

<del>Deleted text</del> and <ins>inserted text</ins> (editorial changes).

Press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> to open the command palette.

<abbr title="HyperText Markup Language">HTML</abbr> are the building blocks of

## 9. Details / Summary — Native Accordion

<details>
<summary>Click to expand this section</summary>

Hidden content lives in here. You can put **markdown** inside, including:

- Lists
- Code blocks
- More accordions

```js
// Even code blocks work inside details
console.log('Hello from inside a details element!');
```

</details>

<details>
<summary>Another collapsible section — CSS tips</summary>

- Use `gap` instead of margins between flex/grid children
- Prefer `clamp()` for fluid typography
- Use logical properties (`margin-inline`, `padding-block`) for RTL support

</details>

<details open>
<summary>This one starts open (the <code>open</code> attribute)</summary>

Some accordions should be open by default. Add the `open` attribute to `<details>` for that behavior.

</details>

## 25. Inline HTML Map (Summary Reference)

| Element                        | Purpose                               |
| ------------------------------ | ------------------------------------- |
| `<mark>`                       | Highlight / emphasis                  |
| `<sub>` / `<sup>`              | Subscript / superscript               |
| `<del>` / `<ins>`              | Deleted / inserted text               |
| `<kbd>`                        | Keyboard key labels                   |
| `<abbr>`                       | Abbreviation with full title on hover |
| `<cite>`                       | Citation / reference                  |
| `<details>` / `<summary>`      | Native accordion                      |
| `<figure>` / `<figcaption>`    | Image with caption                    |
| `<progress>`                   | Progress bar                          |
| `<meter>`                      | Gauge / scalar value                  |
| `<dl>` / `<dt>` / `<dd>`       | Description list                      |
| `<fieldset>` / `<legend>`      | Form grouping                         |
| `<audio>`                      | Audio player                          |
| `<iframe>`                     | Embedded content (video)              |
| `<blockquote>` with `<footer>` | Pull quote with attribution           |
| `<div>` (styled)               | Callout boxes, grid layouts, cards    |
